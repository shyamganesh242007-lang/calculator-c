# Simple Calculator in C

## Overview

This is a simple calculator developed using C programming. It performs basic arithmetic operations using a menu-driven approach.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Repeat calculations (Y/N)

## Concepts Used

- Variables
- Input and Output
- Switch Case
- Arithmetic Operators

## How to Run

Compile the program:

```bash
gcc main.c -o calculator
```

Run the program:

```bash
.\calculator.exe
```
